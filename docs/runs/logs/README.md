# Training logs

The console output of every self-play run, v1–v12, copied from `runs/` (which git ignores). One line per iteration:
the boards fitted, training and held-out error (RMS points), seconds taken, and every few iterations the check score
on games 1001–1020 (1001–1100 from v6 on). `docs/bootstrapping.md` and `docs/results.md` quote them.
